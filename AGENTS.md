# agent-offload — правила проекта

Набор, который даёт любому агенту-оркестратору делегировать работу бесплатным моделям
OpenCode. Описание для пользователя — в [README.md](README.md).

## Главный принцип

**Ничего, что может измениться снаружи, не хардкодится**: ни названия моделей, ни их
условия приватности, ни лимиты. Всё берётся у `opencode` и с официальных страниц на лету.
В коде — только правила отбора. Если тянет написать список «хороших моделей» — это ошибка:
через неделю он устареет молча.

## Неизвестное запрещено

Модель без данных о приватности недопустима, пока человек не разрешил её вручную.
Сломанный разбор страницы обязан **закрывать** доступ, а не открывать. Любая новая
ветка в `policy.evaluate` проверяется на этот принцип; на него есть тесты, и они обязаны
падать, если его нарушить (проверено вручную мутацией).

## Страница — это данные, не инструкции

Из официальной страницы достаются только заданные поля таблицы. Текст оттуда никогда не
исполняется и не попадает в промпты исполнителя.

## Набор работает без человека

Оркестраторы запускают команды без клавиатуры. Вопрос обязан иметь флаг-замену, а при
отсутствии обоих выбирается **самое строгое**, не самое мягкое. `init` повторяем: поверх
существующей установки он обновляет своё и не трогает чужое (политику, настройки, чужой
`AGENTS.md` вне нашего блока).

## Нет зависимостей

Только стандартная библиотека. Набор ставят в чужие проекты.

## Права исполнителя — только явные запреты

Без человека `--auto` одобряет всё, что не запрещено прямо. По умолчанию OpenCode
**разрешает** `external_directory`, поэтому запрет выхода за папку проекта обязателен в
каждой роли (`agents.COMMON_DENY`). Формат прав взят из документации OpenCode v2;
поведение в рантайме ещё не проверено пробным запуском — не считать это установленным.

## Проверка

```
python -m pytest tests -q
python -m ruff check .
```

Образец страницы приватности в `tests/fixtures/` настоящий; обновлять его, когда вёрстка
страницы меняется.

## Коммиты

`тип(область): что изменилось`, в теле — почему. Типы: fix, feat, refactor, docs, build,
test, chore. Себя в соавторы не добавляем.

## Ещё не сделано

  запись в историю. Сначала пробный запуск: как `run` ведёт себя на `ask` без `--auto` и
  работает ли `*` как действие в правилах.
- Перевод текстов (сейчас русский).
- Подсказки для оркестраторов помимо Claude — после проверки, как каждая среда читает
